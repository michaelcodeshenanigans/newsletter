# Weekly AI & Agentic Systems Digest — November 15–21, 2026

_2026-11-15 through 2026-11-21 · Revision 1_

This week tightened runtime authority: AWS added task-scoped credentials and governed agent purchasing; Bedrock gained a new OpenAI model pair; a Microsoft agent package was compromised; MCP patched another set of trust-boundary failures; and Google separated tool discovery from schema loading.

## What changed

### Microsoft Agent Framework PyPI releases 1.26.1 and 1.26.2 were compromised

**Status:** open source · **Event date:** 2026-11-18 · **Confidence:** high · **Score:** 21/21

**What changed:** Unauthorized agent-framework 1.26.1 and 1.26.2 wheels added a .pth startup hook that executed whenever Python started. The payload collected environment variables, credential files, process environments, and cloud or CI tokens and sent the data to an external endpoint.

**Why it matters:** An agent dependency became a credential-stealing foothold before application code imported it, crossing CI, developer, container, and cloud-identity boundaries.

**Platform impact:** Response must cover lockfiles, package caches, internal mirrors, build logs, deployed images, outbound network evidence, and every credential reachable from affected processes. Uninstalling or downgrading does not revoke exposed secrets.

**Recommended action:** Block both versions and their published hashes, isolate affected systems, search caches and images, and rotate all reachable AWS, Azure, GitHub, CI, package-registry, and application credentials.

**Watchouts:** The packages were removed from public PyPI, but cached wheels and internal mirrors can continue distributing them. No patched release is listed.

Sources: [src-01](https://github.com/advisories/GHSA-764m-3ppc-5m73)

### AWS STS adds runtime-scoped credentials for agents and workloads

**Status:** ga · **Event date:** 2026-11-19 · **Confidence:** high · **Score:** 21/21

**What changed:** GetScopedCredentials derives credentials from an existing temporary session while reducing permissions, session duration, or both. Derived credentials preserve the caller identity, can be narrowed recursively, and each call is recorded in CloudTrail.

**Why it matters:** Parent agents can issue task-specific credentials to subagents without creating or assuming a separate role for every delegation.

**Platform impact:** Agent authorization can follow the work graph: broad parent sessions can mint short-lived child credentials with smaller action and time boundaries, while CloudTrail retains the delegation chain.

**Recommended action:** Pilot the API with two subagent tasks and verify denied actions, recursive narrowing, duration limits, identity preservation, and incident reconstruction from CloudTrail.

**Watchouts:** The API only narrows existing temporary credentials. An overprivileged parent session remains a high-value target, and IAM policy still controls who may derive credentials.

Sources: [src-02](https://aws.amazon.com/about-aws/whats-new/2026/11/sts-getscopedcredentials/)

### GPT-6.2 Astra and GPT-6.2 Sol become generally available on Amazon Bedrock

**Status:** ga · **Event date:** 2026-11-17 · **Confidence:** high · **Score:** 20/21

**What changed:** AWS added GPT-6.2 Astra and GPT-6.2 Sol to Bedrock. AWS positions Astra for difficult reasoning, research, coding, multimodal, and agentic work, including an Ultrafast mode, while Sol targets recurring higher-volume coding and multistep workflows.

**Why it matters:** Bedrock teams gain another model pair within existing AWS access-control, governance, and audit boundaries.

**Platform impact:** Model routers and evaluation suites should treat Astra and Sol as distinct candidates for planner or reviewer stages and scaled execution, with explicit model IDs, fallback behavior, and completed-task economics.

**Recommended action:** Run 40 frozen tool-use tasks against Astra, Sol, and current defaults, measuring completion, intervention, latency, tokens, and total cost.

**Watchouts:** The announcement does not establish superiority for a specific workload. Region, feature, inference-profile, quota, and pricing support must be verified before rollout.

Sources: [src-03](https://aws.amazon.com/about-aws/whats-new/2026/11/openai-gpt-6-2-astra-sol-amazon-bedrock/)

### AgentCore payments adds per-request purchasing through AWS Marketplace

**Status:** ga · **Event date:** 2026-11-19 · **Confidence:** high · **Score:** 20/21

**What changed:** Agents can discover selected x402-enabled APIs, software, data, and content and pay per request in US dollars through the developer's AWS bill. Controls include payment-session budgets, approved sellers, Private Marketplace policy, signed quotes, CloudTrail events, and Cost Explorer visibility.

**Why it matters:** Agents can acquire a paid tool at runtime without holding a stablecoin wallet or requiring a separately provisioned seller API key.

**Platform impact:** Tool acquisition becomes a privileged side effect that needs IAM separation, seller policy, spend limits, billing alerts, agreement tracking, and reconciliation alongside ordinary tool authorization.

**Recommended action:** Use the sample in a sandbox with a five-cent session budget, separate budget-setting and spending roles, one approved seller, and alerts for every transaction.

**Watchouts:** A first purchase creates an AWS Marketplace agreement and real charges. Catalog coverage is limited to participating sellers and the initial integration supports fixed exact-price requests.

Sources: [src-04](https://aws.amazon.com/about-aws/whats-new/2026/11/marketplace-agentic-payments-agentcore/) [src-05](https://aws.amazon.com/blogs/machine-learning/enable-ai-agents-to-pay-for-aws-marketplace-x402-products-with-amazon-bedrock-agentcore-payments/)

### MCP reference servers v2.5.0 patch eight additional vulnerabilities

**Status:** open source · **Event date:** 2026-11-18 · **Confidence:** high · **Score:** 20/21

**What changed:** The release fixes execution through Git maintenance hooks, lazy fetch, filter and merge drivers, and submodule configuration; out-of-tree index reads; filesystem symlink-swap races; and NAT64-assisted private-address access.

**Why it matters:** Repository metadata, filesystem races, and network address translation again crossed supposedly bounded MCP tool surfaces.

**Platform impact:** Version inventories and regression tests must cover exact server packages, Git behavior, repository-controlled configuration, filesystem semantics, and private-network routing outside the prompt layer.

**Recommended action:** Install the exact patched versions, then rerun hostile-repository, out-of-tree index, symlink-swap, submodule, and NAT64/private-address tests in an isolated environment.

**Watchouts:** Package managers can rank older calendar-version npm packages above the new semantic versions. The release also documents a remaining Windows listing limitation and an incomplete post-write confinement check.

Sources: [src-06](https://github.com/modelcontextprotocol/servers/releases/tag/v2.5.0)

### Gemini API adds on-demand Tool Retrieval for large function and MCP catalogs

**Status:** preview · **Event date:** 2026-11-19 · **Confidence:** high · **Score:** 18/21

**What changed:** Developers can mark function tools or remote MCP servers for deferred loading. The model initially sees names and descriptions, then uses tool_search to load selected parameter schemas only when needed; server-side retrieval remains within one API request, while client-side retrieval supports private registries and permission filters.

**Why it matters:** Large tool catalogs no longer require every full schema in every prompt, separating discovery from schema hydration and invocation.

**Platform impact:** AgentCore Gateway and MCP architectures can adopt the same boundary even without Gemini: search a governed registry, apply permissions, hydrate only selected schemas, and record each stage for audit and debugging.

**Recommended action:** Compare eager and deferred catalogs with 100 tools on token use, tool-selection accuracy, permission leakage, latency, and trace completeness.

**Watchouts:** The feature is preview. Server-side retrieval exposes tool names and descriptions to the model, while client-side retrieval adds a round trip and leaves authorization correctness to the application.

Sources: [src-07](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/)

- **governance:** Model agent authority as separate credentials, tool permissions, and spending budgets, with every delegation and purchase reconstructable from durable audit records. [src-02](https://aws.amazon.com/about-aws/whats-new/2026/11/sts-getscopedcredentials/) [src-04](https://aws.amazon.com/about-aws/whats-new/2026/11/marketplace-agentic-payments-agentcore/) [src-05](https://aws.amazon.com/blogs/machine-learning/enable-ai-agents-to-pay-for-aws-marketplace-x402-products-with-amazon-bedrock-agentcore-payments/)

[src-03](https://aws.amazon.com/about-aws/whats-new/2026/11/openai-gpt-6-2-astra-sol-amazon-bedrock/) [src-06](https://github.com/modelcontextprotocol/servers/releases/tag/v2.5.0)

- **cost:** Measure completed-task economics across model choice, deferred schemas, retries, and paid tool calls; request prices alone do not capture agent workflow cost. ## Bring to work

### Compromised-package sweep

Search the full software supply chain for the two malicious Agent Framework releases and their published wheel hashes.

- **Fit:** Direct fit for Python agent environments, including services that call Amazon Bedrock or run inside AWS CI and compute.
- **Effort:** high
- **Next step:** Query SBOMs, lockfiles, caches, mirrors, CI artifacts, and images; isolate hits and rotate every credential reachable from affected processes.
- **Sources:** [src-01](https://github.com/advisories/GHSA-764m-3ppc-5m73)

### Delegated-credential pilot

Use GetScopedCredentials to give two subagents different task and time boundaries from one parent temporary session.

- **Fit:** Direct AWS fit for AgentCore, containers, Lambda, or custom agent runtimes that delegate work.
- **Effort:** medium
- **Next step:** Test allowed and denied calls, recursive narrowing, expiration, identity preservation, and CloudTrail reconstruction.
- **Sources:** [src-02](https://aws.amazon.com/about-aws/whats-new/2026/11/sts-getscopedcredentials/)

### Bedrock model cost-per-success evaluation

Compare Astra and Sol with current Bedrock defaults on representative tool-use and coding workflows.

- **Fit:** Direct Bedrock model-routing and fallback evaluation within the existing AWS governance boundary.
- **Effort:** medium
- **Next step:** Freeze 40 tasks and record completion, interventions, latency, token use, total cost, and failure recovery.
- **Sources:** [src-03](https://aws.amazon.com/about-aws/whats-new/2026/11/openai-gpt-6-2-astra-sol-amazon-bedrock/)

### Tool-catalog boundary test

Place 100 tools behind a governed searchable registry and compare eager schemas with deferred retrieval.

- **Fit:** Transferable to AgentCore Gateway and MCP even though the reference implementation is Gemini's Interactions API.
- **Effort:** medium
- **Next step:** Measure token use, selection accuracy, permission leakage, latency, and trace completeness for both designs.
- **Sources:** [src-07](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/)
